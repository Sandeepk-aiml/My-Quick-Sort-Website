function quickSort(arr, lo, hi)
if lo < hi then
pivot ← arr[hi]
i ← lo − 1
for j ← lo to hi − 1 do
if arr[j] ≤ pivot then
i ← i + 1
swap(arr[i], arr[j])
swap(arr[i+1], arr[hi])
p ← i + 1
quickSort(arr, lo, p−1)
quickSort(arr, p+1, hi)
end if
Partition strategy: Lomuto scheme
Pivot is always the last element in the subarray.
